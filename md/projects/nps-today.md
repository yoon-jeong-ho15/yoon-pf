한국투자증권 API를 활용해 코스피 200 종목의 연기금 일별 순매수 흐름을 수집하고, Supabase에 적재한 데이터를 웹에서 시각화하는 금융 데이터 트래킹 서비스입니다. 흩어져 있는 투자자 매매동향 데이터를 자동으로 모아 사용자가 종목별 수급 변화를 빠르게 확인할 수 있도록 구성했습니다.

### 주요 특징

- **한국투자증권 API 기반 연기금 수급 수집**
  종목별 투자자 매매동향 API에서 영업일, 기금 순매수 수량, 순매수 거래대금 데이터를 추출합니다. 코스피 200 종목을 대상으로 반복 조회하며, API 연속 조회와 호출 간 대기 처리를 넣어 안정적으로 데이터를 확보하도록 설계했습니다.

- **Supabase 중심의 데이터 저장 구조**
  `company_list` 테이블에서 수집 대상 종목코드를 불러오고, 수집 결과는 `kospi_fund_net_buy` 테이블에 저장합니다. 날짜와 종목코드를 기준으로 업서트해 같은 데이터가 중복 적재되지 않도록 처리하고, 대량 데이터는 배치 단위로 나누어 전송합니다.

- **AWS Lambda를 활용한 일별 자동 갱신**
  하루치 데이터를 수집하는 Lambda 진입점을 별도로 구성해 운영 환경에서 주기 실행할 수 있도록 만들었습니다. 실행 날짜를 이벤트로 받을 수 있고, 값이 없으면 당일 날짜를 기본값으로 사용해 자동화된 일별 업데이트 흐름을 지원합니다.

- **종목 추가와 과거 데이터 보강을 고려한 운영 스크립트**
  신규 종목이 추가되었을 때 기존 데이터의 날짜 범위를 Supabase에서 조회한 뒤, 해당 종목의 과거 연기금 순매수 데이터를 다시 수집해 채울 수 있는 보강 스크립트를 마련했습니다. 단순 일회성 크롤러가 아니라 데이터셋을 계속 유지보수할 수 있는 구조로 확장했습니다.

- **React 기반 금융 데이터 시각화 화면**
  React Router, TypeScript, TailwindCSS 기반의 프론트엔드에서 누적된 연기금 순매수 데이터를 종목별로 탐색하고 차트로 확인할 수 있게 구성했습니다. 숫자 중심의 원천 데이터를 사용자가 읽기 쉬운 흐름과 변화량 중심의 대시보드로 전환하는 데 초점을 맞췄습니다.
