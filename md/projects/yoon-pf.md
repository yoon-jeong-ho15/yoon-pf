개인 포트폴리오 겸 개발 블로그, 학습 노트 등을 제공하기 위해 직접 기획부터 디자인, 개발, 배포까지 전 과정을 수행하며 운영 중인 정적 웹사이트입니다. 단순한 이력서를 넘어, 개발자로서의 기술적 역량과 철학을 보여주기 위해 최신 웹 기술과 최적화 기법을 적극적으로 도입하여 구축했습니다.

### 주요 특징

- **마크다운 기반의 확장형 콘텐츠 파싱 시스템**
  외부 CMS 없이 `md` 디렉토리의 파일만으로 블로그, 학습 노트, Pedia, 프로젝트 소개를 관리할 수 있도록 구성했습니다. `remark`와 `rehype` 기반 파이프라인에 수식 렌더링(`remark-math`, `rehype-katex`), 코드 하이라이팅(`rehype-highlight`), heading slug 생성(`rehype-slug`)을 연결해 개발 글, 알고리즘 정리, CS/수학 노트처럼 형식이 다른 문서도 일관된 웹 콘텐츠로 렌더링합니다.

- **프론트매터 기반의 다목적 콘텐츠 구조화**
  `gray-matter`로 각 마크다운 파일의 제목, 날짜, 태그, 스택, 링크 같은 메타데이터를 추출하고, 콘텐츠 성격에 맞게 목록/상세 화면을 구성합니다. 프로젝트 소개는 모달 형태로, 학습 노트는 카테고리 트리와 동적 라우팅으로, 블로그는 독자적 탐색 흐름에 맞춰 보여주도록 설계해 하나의 저장 방식으로 여러 종류의 콘텐츠를 운영할 수 있습니다.

- **Next.js App Router와 인터랙티브 UI의 결합**
  Next.js App Router를 기반으로 서버에서 파일 시스템의 마크다운 데이터를 읽고, 필요한 부분만 클라이언트 컴포넌트로 분리했습니다. 첫 화면의 타이핑 애니메이션, About 페이지의 macOS 스타일 드래그 카드, 프로젝트 상세 모달처럼 정적인 포트폴리오에 머물지 않고 사용자가 직접 탐색하는 느낌을 주는 인터랙션을 더했습니다.

- **학습 노트 탐색을 위한 검색과 카테고리 트리**
  학습 노트는 디렉토리 구조를 그대로 카테고리 트리로 변환하고, `index.md`를 카테고리 설명으로 활용합니다. 검색 페이지에서는 제목, 태그, 주제, 강의자 같은 프론트매터 필드를 대상으로 결과를 나누어 보여주고, 검색어 하이라이트를 적용해 많은 노트 사이에서도 필요한 내용을 빠르게 찾을 수 있도록 했습니다.

- **링크 메타데이터 프리페치와 컴포넌트 개발 환경**
  `prebuild` 단계에서 마크다운 프론트매터의 외부 링크를 스캔하고, Open Graph 제목/설명/이미지/아이콘 정보를 `.cache`에 저장해 링크 프리뷰가 매번 외부 네트워크에 의존하지 않도록 했습니다. 또한 Storybook, Vitest, Playwright 기반의 개발 환경을 갖춰 버튼, 카드, 이미지 fallback, 모달 같은 공통 UI를 독립적으로 확인하고 점진적으로 검증할 수 있게 구성했습니다.
