네이버 해피빈, 텀블벅 류의 프로젝트 기반 크라우드펀딩형 기부 플랫폼입니다.

### 주요 특징
- **회원 타입 분리** : 일반 후원자 및 모금 관리자(프로젝트 게시 가능)로 권한 분리
- **맞춤형 메인 페이지** : 사용자 관심사 및 후원 내역(등급) 기반으로 추천 카테고리 프로젝트 노출
- **소식 게시판** : 후원금 전달 및 프로젝트 이후의 근황을 후원자들과 공유

### 주요 기여 사항
- **데이터베이스 설계 주도** : 게시판 종류별(기부/소식) 테이블 분리 및 첨부파일 테이블 통합
- **게시글 관리 전반 개발** : 웹 기반 텍스트 에디터(TinyMCE) 연동, 작성 상태에 따른 이미지 저장/삭제 경로 분리 로직 구현
- **협업 프로세스 수립** : 기능별 Git 브랜치 전략 수립 및 주기적 동기화 체계 마련으로 협업 안정화
